# Security

For a suspected vulnerability, use this repository's **Security → Report a
vulnerability** feature if available. Otherwise contact the repository owner
privately through their GitHub profile.

Include the version, the affected component and reproducible steps.
Remove API keys, account tokens, pairing secrets and personal records from reports.

This release serves its main interface on the local PC by default.
The optional Android receiver uses the PC's Tailscale interface and a
per-installation pairing secret. Review tools and account permissions before
enabling integrations on a shared computer.
