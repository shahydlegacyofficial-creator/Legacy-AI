# Legacy AI 3.24.0

Installable voice and text assistant for Windows 10 and 11, with Claude,
local Kokoro speech, PC tools and optional account integrations.

## Downloads

- `Legacy-AI-3.24.0-Windows-x64-Setup.exe` — Windows installer with Node.js, packages and default models.
- `Legacy-AI-3.24.0-Source.zip` — GitHub-ready source and build scripts.
- `.sha256` files — checksums for the corresponding downloads.

## This release

- Public source package and setup documentation.
- MIT license for original code, with Legacy AI logo rights reserved.
- Branded installer, Windows shortcuts and application.
- GitHub workflow for building draft releases.

## Setup

Open Legacy AI after installation and enter your Anthropic API key.
Add Deepgram for microphone transcription and configure other services as needed.
The included public configuration starts with blank credentials.

Legacy Link supplies Android banking and other selected notification alerts.
The Windows installer is unsigned.
